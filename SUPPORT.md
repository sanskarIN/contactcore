# Support

## Getting help

Before requesting support, check:

1. `README.md` for quick-start commands.
2. `docs/setup.md` for tool installation and platform setup.
3. `docs/troubleshooting.md` for known setup and runtime problems.
4. Existing GitHub issues for a matching report.

For reproducible bugs, use the GitHub bug-report template and include the ContactCore version/commit, operating system, exact steps, expected behavior, actual behavior, and sanitized logs if relevant. Use fictional contact data only.
