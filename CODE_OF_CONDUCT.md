# Code of Conduct

ContactCore aims to provide a welcoming, technically focused open-source community.

## Expected behavior

Contributors and participants should:

- communicate respectfully and assume good faith while still reviewing work critically;
- discuss ideas and code rather than attacking people;
- accept constructive feedback and correct mistakes;
- protect privacy by using fictional data in issues, tests, screenshots, and examples;
- avoid harassment, discrimination, threats, sexualized attention, doxxing, spam, and deliberately disruptive behavior;
- respect maintainers' decisions about project scope, security embargoes, and release readiness.

## Scope

This applies to repository issues, pull requests, discussions, code review, project-managed communication spaces, and public interactions where someone is clearly representing ContactCore.

## Enforcement

Report conduct concerns privately to `sanskarin@outlook.in`. Include relevant links or context without redistributing unnecessary personal information. Maintainers may edit or remove inappropriate content, issue warnings, temporarily restrict participation, or permanently remove participants when needed to protect the community.

Reports will be handled as privately as practical. Retaliation against someone who raises a good-faith concern is not acceptable.
