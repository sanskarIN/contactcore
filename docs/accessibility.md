# Accessibility

ContactCore targets WCAG-oriented desktop accessibility practices: logical keyboard order, visible focus styles, text labels beside fields, keyboard shortcuts (`Ctrl+N`, `Ctrl+S`, `Ctrl+F`, `Esc`), scalable layout, and status text that does not depend on color alone.

Before a stable release, manually test keyboard-only navigation and screen readers on each supported operating system. Automated UI accessibility checks remain a roadmap item because they require platform-specific harnesses.
